# Expense Tracker Management System

A simple PHP and MySQL based Expense Tracker application that helps users manage daily expenses efficiently. Users can add, update, delete, and view expenses with category-wise tracking.

---

## Features

- User Login & Registration
- Session Management
- Add New Expense
- Update Expense Details
- Delete Expense
- View All Expenses
- Category-wise Expense Management
- Total Expense Calculation
- Simple and User-Friendly Interface

---
